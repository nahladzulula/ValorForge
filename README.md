# ValorForge

ValorForge enables high-performance, containerized deployment of scalable systems via automated service-discovery and dynamic builder frameworks.

ValorForge is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/ValorForge.git`
2. `cd ValorForge`
3. Install in editable mode: `pip install -e .`

## Configuration

ValorForge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
